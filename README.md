# ru-court-fee — калькулятор госпошлины в суд (НК РФ, 2024+)

Маленькая библиотека без зависимостей для расчёта государственной пошлины в суды Российской Федерации по **ст. 333.19** (суды общей юрисдикции, мировые судьи) и **ст. 333.21** (арбитражные суды) НК РФ в редакции Федерального закона от 08.08.2024 № 176-ФЗ (действует с 08.09.2024).

Онлайн-версия без установки: **[калькулятор госпошлины на yriist.ru](https://app.yriist.ru/free/court-fee-calculator)** — там же другие бесплатные [юридические инструменты](https://yriist.ru/instruments).

## Что считает

- имущественные иски в СОЮ — 10-ступенчатая шкала, максимум 900 000 ₽;
- имущественные иски в арбитраж — 5-ступенчатая шкала, максимум 10 000 000 ₽;
- иски потребителей — льгота до 1 млн ₽ и пошлина с превышения (подп. 4 п. 2, п. 3 ст. 333.36 НК РФ);
- судебный приказ — 50% пошлины;
- фиксированные пошлины: неимущественные требования, апелляция, кассация.

## Пример

```ts
import { propertyClaimFee, consumerClaimFee, courtOrderFee } from "ru-court-fee";

propertyClaimFee(250_000);                 // 8 500 ₽  (4 000 + 3% × 150 000)
propertyClaimFee(250_000, "arbitration");  // 17 500 ₽ (10 000 + 5% × 150 000)
consumerClaimFee(1_500_000);               // 5 000 ₽
courtOrderFee(250_000);                    // 4 250 ₽
```

Суммы в рублях, результат округляется до полного рубля (п. 6 ст. 52 НК РФ).

```bash
bun test
```
